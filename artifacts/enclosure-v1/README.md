# 颔语低矮底盒 v1

`gesture-bridge-enclosure-v1.3mf` 包含低矮底盒、可拆让位顶盖和两片可选小型模块托片，单位为毫米。主板平放底部，云台固定在盒底，上层舵机与摄像头外露。预览里的摄像头/云台是示意，不在打印文件中；顶盖在预览中上移 9 mm 展示拆装关系。

## 尺寸

| 项目 | 尺寸或处理 |
| --- | --- |
| 舵机支架底座 | 用户确认 36×33 mm；盒底有绑带槽和长孔，真实孔距尚未提供 |
| 云台总高度 | 用户确认 80 mm；底座安装平面为盒内 Z=3 mm |
| 下部包覆高度 | 暂将用户的 45 mm 理解为合盖高度：盒体 41 mm＋盖板 4 mm |
| 盒体 | 外形 160×120×41 mm；底厚、壁厚 3 mm；合盖高 45 mm |
| 内部名义空间 | 154×114×38 mm，角柱、喇叭托台及中央云台占用部分空间 |
| 顶盖中央开口 | 108×92 mm、圆角 8 mm；不制作高于盖板的围墙 |
| 喇叭 | 用户确认 30×27 mm；正面开口 31×28 mm，内侧托台深 16 mm，两侧有绑带槽 |
| 麦克风 | 用户确认直径 7 mm；正面右侧孔 Ø7.6 mm，旁边有绑带槽 |
| 可选模块托片 | 每片 46×43×约4.2 mm，只供尺寸合适的小模块使用，不是主板定制托架 |

100 mm 不再作为盒高，36×33 mm 不作为主板尺寸。两块主板平放后的宽深、插头高度、孔距，以及喇叭厚度和麦克风后部尺寸仍待测量。160×120 mm 是暂定占地，本模型尚未进行实物装配验收。现有云台从盒底固定后预计总高约 83 mm，不含额外垫片。

## 装配方式

1. 云台静止底座固定在盒底的长孔/绑带槽处，核对真实孔位。绑带不能捆住运动关节。
2. 两块主板平放在中央云台周围，使用底部绑带槽、绝缘垫及适当支撑固定；避开焊点、插头、天线和发热元件。最终板位必须按真实占地核对。
3. 喇叭从正面开口装入，放在内侧托台，通过两侧槽固定外框，不压振膜。窗口与上部让位口连通，便于安装，固定依靠托台和绑带。厚度仍需核对。
4. 麦克风探头从 Ø7.6 mm 孔露出，用适合的绝缘衬套、后部线夹固定，不堵拾音孔。喇叭与麦克风回声、振动影响仍需实测。
5. 主板接线从左右及背面开放检修口引出，没有假定 USB 接口的精确坐标。
6. 顶盖从上方套过云台，中央开口让上层机构外露。若摄像头妨碍套入，先拆上层可拆支架再装盖，不要掰开盖板。
7. 顶盖四角通孔 Ø3.4 mm，对应盒体 Ø2.7 mm、深 15 mm 导孔。可先试用适合塑料的约 3 mm 直径、总长约 10 mm 自攻螺钉；普通 M3 机牙螺钉不能视为已有配套螺纹直接使用。先试孔，不用过长螺钉。
8. 云台线材保留活动余量，固定静止端。108×92 mm 让位口依据草图约 75–80 mm 前后尺寸预留，但转轴位置、偏心和线缆扫掠均未实测，不保证任意角度无干涉。先断电核对间隙；本任务不恢复舵机试动。

## 打印与检查

- 全套排版约 286×212 mm，较小打印机请在切片软件中分批排列。另附 `enclosure_body.3mf`、`gimbal_top_deck.3mf`，主要单件占地均为 160×120 mm。
- 盒底朝下、盖板平放、小托片平放，所有零件落在 Z=0。可先以 0.2 mm 层高、至少 3 圈外壁试切片；局部孔洞桥接/支撑按实际打印机检查。
- 四个网格检查了封闭性、绕序、单一连通实体及正体积；标准 3MF 写出后重读网格，并用独立导入器核对零件数与空间范围。
- 网格验证不代替打印公差、强度及实物配合验收。建议测齐主板占地和云台运动包络后再正式打印。
- `validation.json` 记录尺寸和检查结果；`enclosure-preview.png` 为结构预览。

参数化生成入口为 `tools/generate_enclosure.py`，默认 `--width 160 --depth 120 --height 41`，依赖位于 `.tools/cad`。本次未访问串口或烧录固件。
