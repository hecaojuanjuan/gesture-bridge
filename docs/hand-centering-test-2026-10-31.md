### 检测挑战

1. **间歇性检测**
   - 大量"无手"和"无效"观察
   - 手部检测不连续
   - 可能原因：手势快速移动、光照、遮挡

2. **多手干扰**
   - 偶尔检测到2只手
   - 系统正确拒绝多手场景

3. **边界框质量**
   - 有些帧box为[0,0,0,0]但hands=1
   - 系统正确识别并跳过

## 核心算法验证

### ✅ 坐标归一化
```python
center_x = (box[0] + box[2]) / 2.0 / width
center_y = (box[1] + box[3]) / 2.0 / height
```
- 输入: 像素坐标 (0-320, 0-240)
- 输出: 归一化坐标 (0.0-1.0)
- **验证通过**

### ✅ 偏差计算
```python
error_x = center_x - 0.5
error_y = center_y - 0.5
```
- 中心点: (0.5, 0.5)
- 容差: ±0.08 (8%)
- **验证通过**

### ✅ 轴选择逻辑
```python
if abs(error_x) >= abs(error_y):
    axis = 'pan'  # 水平轴
else:
    axis = 'tilt'  # 俯仰轴
```
- 优先移动偏差较大的轴
- **验证通过**

### ✅ 居中确认
- 需要连续3次观察在容差内
- 观察#138达到1次，但后续帧无效
- 观察#155达到1次，但后续帧无效
- **逻辑正确，但受限于检测连续性**

## 结论

### ✅ 算法验证成功

1. **坐标系统**: 归一化计算正确
2. **偏差判断**: 中心容差±8%工作正常
3. **控制决策**: 正确选择需要移动的轴和方向
4. **居中检测**: 能够识别手势已居中的状态

### ⚠️ 实际应用挑战

1. **检测稳定性**: 手部检测间歇性强，影响连续居中判断
2. **多手干扰**: 需要保持单手环境
3. **帧有效性**: 约18%的观察有有效手部数据
