## 源码核实与最小接入

- 官方摄像头只统计帧。新增借用帧回调，复制后立即归还驱动缓冲；应用槽固定为两个，待处理槽最多一个。
- 官方 RGB 推理 API 已存在；连续链路直接调用它，禁用静态 bus.jpg 启动示例。
- 官方 `yaw`/`roll` 为绝对二维比例，不用于动作识别。直接公开双眼坐标，以 `atan2(dy,dx)` 折叠至 ±90° 的图像眼线特征供独立 C 核心消费。
- 官方 YOLO 后处理已将低可见性关键点写成零；再要求单人、人体分数 ≥0.5、鼻/双眼有效且在图像内、眼间距 ≥4 像素。没有虚构额外的人脸追踪 API；误检/漏检需要实测。
- 固定词典及缓存音频由本地代码管理；没有调用文档中拟定的 `hv.*` 平台 API。
- 正式表达使用独立官方 `qm_audio_control` 与常驻 PCM，按真实 operation 状态检查完成/抢占/错误并释放。未知播放结果不自动重试。
- 官方资源模式只关闭上传，无法独占 TTS；因此确认后先结束当前会话，再短暂占用音频。联网不关闭，后续唤醒仍走官方入口。

以上是第一阶段原型与编译/主机验证交付，不是完整产品或赛事验收结论。
