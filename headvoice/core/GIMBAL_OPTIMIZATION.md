# 摄像头居中算法优化说明

## 问题分析

### 原有问题
1. **识别要求太苛刻**：必须恰好1人且头部完全有效，否则直接停止
2. **响应时间太慢**：每次调整后等待450ms，总共可能需要20+ 秒

## 优化方案

### 1. 放宽人像识别条件（核心优化）

**原来**：
```c
if (people != 1 || !headValid || ...)
  return stop(core, HV_GIMBAL_NO_FACE);
```

**现在**：
- 允许 1-2 人（多人场景也能工作）
- 即使头部检测无效，只要坐标合理（0.1-0.9范围）也尝试居中
- 不立即停止，给更多等待机会

**效果**：显著提高识别成功率，特别是侧脸、低头等场景

### 2. 加快响应速度

| 参数 | 原值 | 优化后 | 改进 |
|------|------|--------|------|
| 初始等待 | 450ms | 250ms | **-44%** |
| 每步等待 | 450ms | 200ms | **-56%** |
| 最小步长 | 10 | 12 | +20% |
| 最大步长 | 35 | 45 | +29% |
| 步长系数 | 100 | 120 | +20% |
| 最大步数 | 20 | 30 | +50% |

**预计总时间**：
- 原来：20步 × 450ms = **9秒** （不含推理时间）
- 现在：15步 × 200ms = **3秒** （通常更少步数）

**时间节省约 60-70%**

### 3. 提高容错性

- **变差阈值**：0.035 → 0.05（更宽容）
- **允许变差次数**：2次 → 3次
- **居中判定范围**：0.08 → 0.06（更精确但需要次数更少）
- **连续居中次数**：3次 → 2次（更快确认）

### 4. 延长总超时

- 总超时：90秒 → 120秒
- 给复杂场景更多时间

## 使用方法

```bash

cp headvoice/core/hv_gimbal_core.c headvoice/core/hv_gimbal_core.c.backup

# 使用优化版本
cp headvoice/core/hv_gimbal_core_optimized.c headvoice/core/hv_gimbal_core.c

# 重新编译
cd .work/headvoice/apps
idf.py build
```

2. **边界测试**：多人、部分遮挡、光线变化
3. **性能测试**：记录实际居中时间和成功率
