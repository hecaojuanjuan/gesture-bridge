# RGB 灯板接入教程

先完成配网面板，再接 RGB 灯板。六轴传感器不参与当前 BLE 配网和灯光功能，可以以后再接。当前接口按官方 GPIO1、8 颗 WS2812 配置。

## 1. 断电并辨认接口

1. 拔掉主板 USB，关闭并断开舵机独立电源。舵机保持断电，不做运动测试。
2. 查看灯板输入端的丝印：电源通常标 `5V` / `VCC`，地标 `GND` / `G`，数据输入标 `DIN` / `DI` / `IN`。
3. 若同时有 `DIN` 和 `DOUT`，使用 `DIN`。只有箭头时，数据方向应从主板进入第一颗灯珠，再沿箭头流向后面的灯珠。
4. 查看主板丝印，找到明确的 `5V`、`GND`、`P1` / `GPIO1`。这里是 GPIO1，不是 GPIO17，也不是排针的“第一个脚”。本教程不假定排针的左右顺序。若只有 `VCC` 而无法确定电压，或灯板输入端标识不清，先通过清晰照片核对，勿按线材颜色猜接。

## 2. 接三根线

全程断电接线：

| 主板 | 灯板输入端 | 作用 |
| --- | --- | --- |
| 明确标记的 5V 供电脚 | 5V / VCC | 灯板供电 |
| GND | GND / G | 共地 |
| P1 / GPIO1 | DIN / DI / IN | 灯光数据 |

官方驱动要求灯板用 5V，不能用主板 3.3V 给灯板供电。摄像头原有 3.3V 接线保持原样。不要将 5V 接到 GPIO1。

官方驱动头文件建议在靠近第一颗灯的数据线上串联 330 Ω 电阻，并在灯板 5V 与 GND 之间并联至少 100 µF 电容。先确认模块是否已经带有这些器件；电解电容的负极接 GND。参考源代码：`vendor/official-sdk/apps/main/peripheral/bsp_ws2812.h`。若需增加器件，仍要在断电时操作。

当前只使用主板 USB 供电路径，不将舵机电源并接到主板 5V。如果以后改用独立灯板电源，需要先核对电源与主板的连接方案，不能直接把两个电源的正极接在一起。

## 3. 通电前复查

逐根核对：5V 对 5V，GND 对 GND，GPIO1 对 DIN；没有插到 DOUT，没有跨到相邻排针，裸露线头不相碰。灯板共 8 颗灯珠时符合当前驱动配置；若实际数量不同，先调整配置。

复查后，只接回主板 USB。舵机电源继续关闭。旧固件可能不会自动点灯，因此“此时不亮”不能直接判定接线或灯板损坏。

## 4. 用新面板固件验证

新面板固件已编译，但尚未烧录。烧录及重新配网应另行执行，不能把编译成功当作上板成功。

烧录完成后：

1. 运行 `./tools/control_panel.ps1`，选择真实 CH343 串口后连接。
2. 在 RGB 页选择红色，应用低亮度，人工观察是否为红色；再分别验证绿色和蓝色。颜色不对应时先记录现象，不反复随机换线。
3. 验证关闭灯光，再点击“自动状态灯”。
4. 已联网设备应在云端连接后显示绿色；未配网设备等待 BLE 配网时蓝色慢闪。已有 Wi-Fi 时无需为了点灯主动清除配网。
5. 确认灯光控制通过后，再按面板引导验证小程序配网以及断网恢复。

面板中的“写入正常”只说明驱动调用成功，灯珠实际亮起和颜色仍需人工确认。若灯板明显发热、出现异味或主板反复重启，立即拔掉 USB，再核对电源与接线。
