# 配网引导与 RGB 控制面板

本地 Python/Tk 桌面面板通过 USB 串口控制设备；配网凭据由官方小程序通过 BLE 下发。支持 GPIO1 上的官方 8 颗 WS2812。此版本不包含舵机控制。

灯板尚未连接时，先按 [RGB 接线教程](rgb-wiring.md) 断电接线。六轴传感器不参与本功能，暂不需要接入。

## 启动

在仓库根目录运行：

```powershell
./tools/control_panel.ps1
```

选择 CH343 对应的真实端口，关闭其他串口监视程序，再点击连接。串口参数为 115200、8N1，打开前 DTR/RTS 均设为 false。面板不自动选择 COM1，不在启动时连接，也不在失败时自动重连。

当前板上旧固件没有面板协议，连接会提示超时。先编译新固件，后续再安排烧录及实机验收：

```powershell
$idfpy = '.tools/espressif/python_env/idf5.4_py3.12_env/Scripts/python.exe'
& $idfpy tools/build.py headvoice build --stage 2 --rotate-cw90 --gimbal
```

此构建保留当前按需推理的云台模式和装配旋转。面板没有舵机命令，软件验证不操作舵机。官方源码保持原样，通过 `tools/prepare_sdk.py` 在构建副本接入。面板模块也会加入 baseline 构建。

## 配网操作

1. 首次无已存 Wi-Fi 时，设备自动进入 BLE 配网。已有网络正常时直接显示连接状态。
2. 手机上打开配套小程序，启用蓝牙及小程序所需权限，添加设备，选择 2.4 GHz Wi-Fi 并输入密码。无需先在系统蓝牙设置手动配对。
3. 面板显示设备回报的阶段；Wi-Fi 获得 IP 与云端连接是两个阶段。绿色只表示云端连接事件已经发生，不证明语音对话通过。
4. 更换网络时，点击“更换 Wi-Fi / 重新进入配网”，阅读弹窗后确认。设备会清除已存 Wi-Fi、配网环境及本地绑定标记，重启进入 BLE 配网；不会请求删除云端账号设备。面板收到命令接受回执后释放串口，等待设备启动再手动连接，核对真正的配网结果。

## 灯光与状态

| 状态 | 自动灯光 |
| --- | --- |
| 等待 BLE 配网 | 蓝色慢闪，约 1 秒周期 |
| 连接 Wi-Fi / 连接云端 | 黄色闪烁，约 0.4 秒周期 |
| 云端已连接 | 绿色常亮 |
| 连接断开 / 初始化失败 | 红色慢闪 |
| 启动 | 低亮白色 |

自动模式中，表达功能的校准、候选确认和播放提示优先于联网提示。手动颜色和关闭灯光覆盖自动提示；点击“自动状态灯”退出手动模式。亮度 0–100%，默认 20%，100% 时每通道仍限制在原厂示例的 48/255。断开面板保持设备当时模式；灯光设置仅存在 RAM，重启恢复默认。

灯光更新由单个任务每 100 ms 执行。命令回执表示配置已接受，回执中的 RGB 是最近一次输出，下一次状态轮询才能反映更新。驱动写入成功不等同于人工确认灯珠亮起。面板约每 1.5 秒轮询，命令等待 4 秒；超时、串口错误或启动日志会将设备状态置为未知。面板不显示原始日志和凭据。

## 接口与验证

串口命令 `hv_panel <id> status|auto|off|color <r> <g> <b>|brightness <0..100>|restart`，ID 范围 0–999999。返回 `PANEL {JSON}`，包含匹配 ID、接受结果、联网阶段、灯光模式、亮度、驱动状态、最近 RGB 输出和运行秒数。主机严格关联 ID，忽略旧回执和其他日志。`restart` 会清除配网并重启，勿当作只读命令。

```powershell
& $idfpy -m unittest discover -s tests -p test_control_panel.py -v
```

主机测试覆盖输入白名单、回执关联、分段串口数据、异常字段、超时及重启。后续实机仍需验证：首次 BLE 配网、已有网络重连、断网/恢复、云端连接、颜色与亮度、手动/自动切换、重新配网及原有语音功能。当前未烧录、未清除设备网络，未将主机测试视为实机验收。
